About LibraX

Digital Library Management System

📚 About the System

LibraX is a front-end digital library management system created to provide a clean and professional interface for managing and discovering digital books.

🔎 Smart book search
❤️ Personal favorites
🔗 Direct online book access
💾 Browser-based data storage
🌙 Dark and light themes
📱 Responsive design

✨ Features

This single-file project uses HTML, CSS and JavaScript. No external framework or server is required for the basic library interface.


Book links are directed to legitimate online sources where the selected book can be accessed.
